# PROJECT_OVERVIEW

## 1. 本プロジェクトについて

本プロジェクトは、対話式進学塾１対１ネッツで実施する
「個別ミッショントレーニング（以下、個トレ）」において使用する
授業運営・学習進捗管理アプリ（gyoumu-app）の開発プロジェクトである。

本プロジェクトは、教室管理OS（netz-os）とは完全に独立した別プロジェクトであり、
設計・仕様・業務範囲を混在させない。

## 2. プロジェクトの目的

本アプリは、1対複数人型の演習授業である
「個別ミッショントレーニング」の授業運営を支援することを目的とする。

授業中に発生する以下の業務を一元管理し、
講師・生徒・管理者が効率よく授業運営・学習管理を行える環境を提供する。

- 学校の進度管理
- 個トレ教材の進捗管理
- 講師への質問・丸付け依頼・SOS
- テスト情報の管理
- 学習アプリとの連携

## 3. 対象業務

本アプリが対象とする業務は以下である。

- 個別ミッショントレーニング授業
- 学校進度管理
- 教材進捗管理
- 講師対応管理
- 学習記録管理
- テスト情報管理
- スキマ君との連携管理

教室全体の業務管理は対象外とする。

## 5. 関連システム

### Google Apps Script

APIおよびデータ処理を担当する。

### Google スプレッドシート

データ保存先として利用する。

### スキマ君

別プロジェクトの学習アプリである。

英単語、古文単語、化学式等の学習および小テストを実施する。

個トレアプリでは以下を行う。

- スキマ君の起動
- 利用ログ管理
- 小テスト結果確認

### Microsoft Forms

テスト情報等の収集に利用する。

### Google Forms

テスト振り返り等の収集に利用する。

## 6. 本プロジェクトの管理方針

本プロジェクトでは、業務仕様・実装・改善案を明確に分離して管理する。

### 業務仕様

教室運営上の正式な仕様。

管理対象：

- PROJECT_OVERVIEW.md
- BUSINESS_SPEC.md
- EXTERNAL_APP_INTEGRATION.md

### 実装仕様

現在コードに実装されている内容。

管理対象：

- CURRENT_IMPLEMENTATION.md

### 差分管理

業務仕様と実装仕様との差異を管理する。

管理対象：

- GAP_ANALYSIS.md

### 改善管理

今後の改善計画を管理する。

管理対象：

- TODO.md
- BACKLOG.md

## 7. ドキュメント作成ルール

1. 推測を事実として記載しない。
2. 業務仕様と実装仕様を混在させない。
3. 未確認事項は「未確認」と明記する。
4. 改善案は「提案」として区別する。
5. コードを理由に業務仕様を書き換えない。
